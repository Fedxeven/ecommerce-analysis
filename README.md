# E-commerce Analysis
Basic e-commerce data analysis using Python and pandas.

## About the project
I analyzed a small synthetic dataset of online store orders.

The goal was to calculate basic business metrics and understand which products and categories generate the most revenue.

## Results
- Total revenue: 64,700
- Number of orders: 15
- Average order value: 4,313.33

### Revenue by product
- Headphones — 20,000
- Backpack — 16,000
- Keyboard — 14,000
- Notebook — 7,500
- Coffee mug — 7,200

### Revenue by category
- Electronics — 34,000
- Accessories — 16,000
- Stationery — 7,500
- Home — 7,200

## Analysis
The highest revenue comes from the Electronics category.

Among individual products, Headphones generated the most revenue.
