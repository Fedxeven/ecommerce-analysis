# E-commerce Analysis
Basic e-commerce data analysis using Python and pandas.

## About the project
I analyzed a small synthetic dataset of online store orders.
The goal was to calculate basic business metrics and understand which products and categories generate the most revenue.

## Analysis
- Total revenue
- Number of orders
- Average order value
- Revenue by product
- Revenue by category

## Tools
- Python
- pandas
- matplotlib

## Files
- `data.csv` — dataset
- `analysis.py` — analysis script
- `revenue_by_category.png` — visualization
